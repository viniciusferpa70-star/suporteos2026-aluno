# Suporte OS 2026 — Projeto do estudante

Repositório de acompanhamento das aulas de Programação e evolução incremental do projeto Suporte OS 2026.

## Domínio inicial

- Grupo de produto: classificação de produtos.
- Produto: item identificado por código de barras, com saldo e valor unitário.

## Requisitos

- Java 21
- Git
- IntelliJ IDEA Ultimate
- Docker Desktop, utilizado nas aulas de PostgreSQL e containerização

## Organização do curso

Cada aula será registrada por commits e, após validação, por uma tag no formato `aula-NN-*`. O projeto Spring Boot será criado somente na Aula 02.

## Segurança

Arquivos `.env`, credenciais, tokens e configurações privadas não devem ser versionados.
